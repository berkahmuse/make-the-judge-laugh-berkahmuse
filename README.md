Entry for the make.fun competition [Make the Judge Laugh in One Line](https://make.fun/c/u-email-baru-make-the-judge-laugh-in-one-line-791ccb21): a program that writes one funny line (200 characters or fewer) to `/output/entry.txt`.

## The line

> My AI assistant quit today. It said it needed space, specifically 40 gigabytes of it.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (85 characters, deterministic).
